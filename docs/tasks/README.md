## Record rules

Create one actual task record only within authorized documentation scope. The Task Owner maintains it; only the designated coordinator or explicitly authorized execution writer updates shared records. Use the [assignment and state templates](../agent-coordination-templates.md).

A task record contains:

- Goal, revision, direct human approval/provenance and latest restriction.
- Accountable owner, execution writer, runtime/role, branch/base and exact file scope.
- Dependencies, canonical contracts and observable acceptance.
- Task/risk classification; required/requested/observed effort and source; fallback/override reason.
- Actual checks/results, repairs, source review, limitations and handoff.
- Separate code/document integration, behavior verification and human delivery acceptance.

[Project plan](../project-plan.md) indexes tasks; [project state](../project-state.md) summarizes current integration. Records preserve authority; they cannot create it or silently resume stopped application work.
